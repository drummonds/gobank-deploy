Performance runs

gobank's performance runs as this page made them: an environment created at a scale, the demo set flat out, customers added for a span and days run for another, the two rates read off /about.json — customers added per second (the demo's own rate, batch by batch) and account days per 12h (the start-of-day pass's rate over the whole day) — then the server removed. The row under each run is the line for benchmark.md. Before the server goes the run also records every route the demo served, its count and p95: the routes over versions. The load tests walk the customer journey from a loader box until a screen is too slow. The scans are the other measure: every route of an environment as it stands, up the concurrency ladder.
